# Just A Blog (JAB)

A modern personal tech blog built using Next.js, Tailwind CSS, and Supabase.

## About

Just A Blog is my personal space where I share:

- Web development tutorials
- AI experiments
- Backend and full-stack projects
- Learning notes
- Thoughts and ideas while building technology

The project focuses on simplicity, clean UI, fast performance, and a minimal reading experience.

---

## Tech Stack

- Next.js 16
- React
- Tailwind CSS
- Supabase
- TypeScript
- Bun

---

## Features

- Modern responsive UI
- Dynamic blog pages
- Supabase database integration
- Clean minimal design
- Blog publishing system
- Fast loading
- Mobile friendly
